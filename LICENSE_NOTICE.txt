ILRM (Inverse Lag Recurrent Memory) is the underlying cell / memory design.
ILRN-4-96 (Inverse Lag Recurrent Network) denotes the four-layer network
containing four separately parameterised ILRM blocks, with pre/post LayerNorm,
residuals, an input embedding and an output head.
